# TrackBox 🎵

TrackBox é uma plataforma de música desenvolvida como projeto pessoal, inspirada em plataformas de streaming como o SoundCloud.

O projeto foi desenvolvido com o objetivo de praticar desenvolvimento web, integração entre frontend e backend, banco de dados e controle de versão com Git e GitHub.

## 🚀 Funcionalidades

- Cadastro de usuários
- Login e logout
- Perfis de usuários
- Upload de foto de perfil e banner
- Pesquisa de músicas, artistas e usuários
- Reprodução de músicas
- Player de música fixo
- Sistema de curtidas
- Curtidas em perfis
- Histórico de músicas reproduzidas recentemente
- Páginas de músicas
- Páginas de artistas
- Páginas de álbuns
- Sistema de acompanhamento de usuários

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git
- GitHub

## 🗄️ Banco de dados

O TrackBox utiliza MySQL para armazenar informações relacionadas aos usuários, músicas, curtidas, histórico de reprodução e outras funcionalidades da plataforma.

As credenciais do banco de dados não são disponibilizadas no repositório público.

## 🎯 Objetivo do projeto

O TrackBox foi desenvolvido como projeto de estudo e portfólio para colocar em prática conceitos de:

- Desenvolvimento web
- Programação backend com PHP
- Desenvolvimento frontend
- Banco de dados relacionais
- Integração entre frontend e backend
- Autenticação de usuários
- Manipulação de dados
- Git e GitHub
